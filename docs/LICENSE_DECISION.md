# License decision guide

No project license has been selected. Publishing source without a license generally leaves copyright rights reserved: people may view it on GitHub but do not receive broad permission to copy, modify, or redistribute it.

| Choice | What it grants | Main consideration |
|---|---|---|
| MIT | Broad use, modification, distribution, and sublicensing with notice; no warranty | Short and common; no express patent grant |
| Apache-2.0 | Similar broad rights plus an express patent license and patent-termination terms | Longer; requires preservation of notices and marking modifications |
| No license | No broad reuse permission | Limits portfolio reuse/contribution and can deter employers from running forks |

Before choosing, inventory third-party code, fonts, icons, screenshots, and generated assets; their licenses remain separate. The project owner should select the license and add the canonical text in a separately approved publication step. This is not legal advice.
